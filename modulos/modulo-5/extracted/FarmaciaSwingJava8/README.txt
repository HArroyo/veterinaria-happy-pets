PROYECTO: FarmaciaSwingJava8
TECNOLOGÍA: Java 8 + Swing
IDE: Eclipse

Incluye 4 pantallas en un único JFrame mediante JTabbedPane:
1. Catálogo de Productos y Fármacos
2. Control de Stock y Lotes
3. Proveedores y Órdenes de Compra
4. Ajustes y Mermas

FUNCIONALIDAD DEMO:
- Tablas JTable
- Formularios Swing
- Búsqueda en tablas
- Alta, edición y eliminación básica en memoria
- Registro simple de movimientos de stock
- Registro simple de ajustes/mermas

IMPORTAR EN ECLIPSE:
1. File > Import...
2. General > Existing Projects into Workspace
3. Select root directory
4. Seleccione la carpeta FarmaciaSwingJava8
5. Finish

EJECUTAR:
- Abra src/com/farmacia/app/Main.java
- Run As > Java Application

NOTA:
- El proyecto no usa librerías externas.
- Está preparado para JavaSE-1.8.
- Los datos son temporales en memoria. La base de datos se puede agregar después con JDBC.
